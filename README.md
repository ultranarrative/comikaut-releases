# Comikaut

**Comics, from script to page.** Write comic scripts panel by panel, lay out the pages, then draw them with pressure brushes, your Procreate brushes included. Export PDFs ready for print, with bleed and trim marks.

Free, for a Mac with Apple silicon, macOS 11 or later. This repository holds the installer only. More free apps at [ultranarrative.com/tools](https://www.ultranarrative.com/tools).

## Download

[Comikaut-mac-arm64.dmg](https://github.com/ultranarrative/comikaut-releases/releases/latest/download/Comikaut-mac-arm64.dmg)

This link always points to the newest version.

## Opening it the first time

I sign Comikaut myself rather than through Apple, so macOS asks once. Open the disk image, drag Comikaut to Applications and open it. When macOS stops it, go to System Settings, then Privacy & Security, and click Open Anyway.
